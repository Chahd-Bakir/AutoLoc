\# AutoLoc



Application de gestion de location de voitures.



\## Acteurs



| Acteur | Rôle |

|---|---|

| \*\*Client\*\* | Consulte les véhicules, réserve, annule, consulte son historique |

| \*\*Agent d'agence\*\* | Traite les réservations, remet et récupère les véhicules |

| \*\*Responsable d'agence\*\* | Gère le parc, les tarifs, les agents et les statistiques |

| \*\*Administrateur\*\* | Gère les comptes, les rôles et les agences |



\## Cas d'utilisation (première liste)



\### Client

\- S'inscrire / se connecter

\- Rechercher un véhicule

\- Réserver un véhicule

\- Annuler une réservation

\- Consulter son historique



\### Agent d'agence

\- Valider une réservation

\- Enregistrer la remise d'un véhicule

\- Enregistrer le retour d'un véhicule

\- Constater l'état du véhicule



\### Responsable d'agence

\- Gérer les véhicules de l'agence

\- Définir les tarifs

\- Gérer les agents

\- Consulter les statistiques



\### Administrateur

\- Gérer les utilisateurs et les rôles

\- Gérer les agences
